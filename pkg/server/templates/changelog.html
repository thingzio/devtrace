Changelog

What's new in DevTrace

April 16, 2026 v0.11.9

  • AI Sensing descriptions — each behavioral metric card now includes a brief explanation of what it measures and its data requirements.
  • Synthetic Risk details visible by default — flag details are now shown inline without requiring a click to expand.
  • Admin dashboard improvements — scoring chart now shows hourly granularity (last 12 hours) instead of daily. Added total contributors and total scored counts alongside queue depth and stale contributors.
  • Tenant management — admin tenants table now supports search by username or name, sortable columns, pagination (25 per page), and tenant deletion.

April 15, 2026 v0.10.x

  • AI Sensing (Pro) — behavioral heuristics for Pro plan: Velocity Anomaly, Active Hours, Burst-Vanish, and Synthetic Risk composite scoring.
  • Score trend chart — contributors scored more than once now show a historical trend chart on their scorecard page.
  • Repository-scoped scoring — score contributors in the context of a specific repo with ?repo=owner/name.
  • Trusted organizations — pass ?trusted_orgs=org1&trusted_orgs=org2 to boost scores for org members.

April 14, 2026 v0.9.x

  • Plan tiers — Free, Starter, and Pro plans with tiered contributor limits, API rate limits, and feature access.
  • GitHub App integration — install the DevTrace GitHub App on your organization to enable background ingestion and continuous scoring.
  • Risk summary — AI-generated narrative summarizing each contributor's reputation, strengths, and areas of concern.
  • Score history API — /api/v1/score/{username}/history endpoint for trend analysis.

April 13, 2026 v0.8.x

  • Initial release — contributor trust scoring across 22 signals in 5 categories (Identity, Behavioral, Community, Engagement, AI Sensing).
  • Dashboard — search and score any GitHub contributor, view quota usage, and recently scored contributors.
  • API access — REST API with Bearer token authentication for programmatic scoring.
  • Theme support — light, dark, and system appearance modes.
