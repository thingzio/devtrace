GitHub App

Installing contributes API capacity to the pool DevTrace scores with, and auto-creates a watchlist for the repositories you grant. Scoring works without it — this is how we keep it working at scale.

Install on your personal account. GitHub caps the search API at 30 requests per minute per installation regardless of account size, so a personal install contributes exactly as much as an organization one. No admin approval, about 15 seconds.

Install GitHub App

Prefer to install on an organization? That works too, but GitHub routes the request to an org owner for approval.
