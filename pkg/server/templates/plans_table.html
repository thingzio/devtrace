How this service is operated

DevTrace is a reference implementation, not a commercial product. There are no plans, no pricing, and no subscriptions — every feature is available to every account.

It is operated on a best-effort basis: no SLA, no uptime guarantee, and no support commitment. Per-account limits exist only to keep the shared instance responsive for everyone using it.

The source for this service is being published under the Apache License 2.0.
